# Smart Technical Events Hub

A full-stack college events management system that helps students discover,
register for, and manage technical events.

## Features

- Browse technical events
- Search and filter events
- Student registration and login
- Event registration
- Bookmark events
- Dashboard
- Admin management
- Notifications
- Responsive design

## Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript
- Bootstrap

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

## Project Structure

- `frontend/` – User interface
- `backend/` – Server, API, database and authentication
